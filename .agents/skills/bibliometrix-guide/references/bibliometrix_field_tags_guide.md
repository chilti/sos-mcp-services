# Canonical Field Tags Dictionary in `bibliometrix`

When loading and converting any bibliographic dataset with `convert2df()`, `bibliometrix` normalizes all columns into a standard set of two-letter tags inherited from the classical Web of Science / ISI format.

---

## 1. Main Field Tag Correspondence Table

| Tag | Field Name | Description and Usage | Typical Format |
|:---:|:---|:---|:---|
| **`AU`** | Authors | List of document authors | `Surname, N.; Surname, N.M.` |
| **`AF`** | Author Full Names | Full names of authors | `Surname, First Middle` |
| **`TI`** | Document Title | Title of the article or chapter | Text in English or original language |
| **`SO`** | Publication Source | Title of the journal, conference, or book | Standard source name |
| **`PY`** | Publication Year | Year of publication | 4-digit integer (e.g., `2024`) |
| **`DE`** | Author Keywords | Keywords assigned by the authors | Separated by semicolon `;` |
| **`ID`** | Keywords Plus | Keywords algorithmically generated by WoS/Scopus | Terms derived from cited titles |
| **`AB`** | Abstract | Document abstract or summary | Structured free text |
| **`C1`** | Author Affiliations | Institutional addresses and affiliations of authors | Institutional format with country |
| **`RP`** | Reprint Address | Corresponding author address | Affiliation and contact email |
| **`CR`** | Cited References | Exhaustive list of cited bibliographic references | `Author, Year, Journal, V, P, DOI` |
| **`TC`** | Times Cited | Global citations received in the database | Integer $\ge 0$ |
| **`UT`** | Unique Identifier | Unique record identifier (WOS ID, Scopus EID, DOI) | Alphanumeric |
| **`DI`** | Digital Object Identifier | Document DOI | `10.xxxx/...` |
| **`DT`** | Document Type | Document type (`Article`, `Review`, `Editorial`, etc.) | Normalized string |
| **`LA`** | Language | Full-text language (`English`, `Spanish`, etc.) | Language name |

---

## 2. Critical Distinction: `DE` (Author Keywords) vs. `ID` (Keywords Plus)

* **`DE` (Author Keywords):** Terms consciously chosen by the authors to index their work. They reflect the **native vocabulary of the research front**. This is the recommended field for `thematicMap(field = "DE")`.
* **`ID` (Keywords Plus):** Terms automatically extracted by Clarivate indexing algorithms from the titles of articles appearing in the cited bibliography (`CR`). They tend to be broader and more frequent, but can introduce conceptual noise into niche thematic maps.

---

## 3. Structure of the Cited References Field (`CR`)

The `CR` field is the essential input for:
1. **Co-citation (`analysis = "co-citation"`):** Two documents jointly cited by a third work.
2. **Bibliographic Coupling (`analysis = "coupling"`):** Two documents that share references in their bibliography.
3. **Price's Index and Half-Life:** Calculation of reference age.

Each record in `CR` is typically formatted as a semicolon-separated (`;`) list:
```text
SMITH J, 2020, SCIENTOMETRICS, V125, P450, DOI 10.1007/s11192-020-03650-1;
GARCIA A, 2018, J INFORMETR, V12, P110, DOI 10.1016/j.joi.2017.12.002
```

## 4. Supported Data Sources in `convert2df()`

| Database | Recommended Export Format | `dbsource` Argument | `format` Argument |
|:---|:---|:---:|:---:|
| **Scopus** | CSV or BibTeX | `"scopus"` | `"csv"` or `"bibtex"` |
| **Web of Science** | Plain Text or BibTeX (Full Record and Cited References) | `"wos"` | `"plaintext"` or `"bibtex"` |
| **PubMed** | Native PubMed / MEDLINE text format | `"pubmed"` | `"pubmed"` |
| **Dimensions** | CSV file exported from the Dimensions platform | `"dimensions"` | `"csv"` |
| **Cochrane Library** | Plain text export | `"cochrane"` | `"plaintext"` |
| **OpenAlex** | JSON exported via API or ClickHouse | `"openalex"` | `"json"` (bibliometrix $\ge 4.2$) |
