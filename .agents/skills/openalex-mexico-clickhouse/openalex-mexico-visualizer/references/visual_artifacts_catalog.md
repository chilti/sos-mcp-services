# Visual Artifacts Catalog and Specification

## 1. Design Principles
The artifacts generated by `openalex-mexico-visualizer` adhere to high-level scientometric visualization standards:
- **Academic Rigor and Clarity:** Free of unnecessary decorative elements; focused on information density and analytical clarity.
- **Canonical Color Palette:**
  - *Diamond:* `#00A86B` (Emerald green / Non-commercial)
  - *Gold (APC):* `#E39918` (Golden yellow)
  - *Hybrid:* `#3B82F6` (Commercial blue)
  - *Green (Repository):* `#10B981`
  - *Bronze:* `#CD7F32`
  - *Closed:* `#6B7280`
  - *World FWCI Benchmark Line:* `#EF4444` (Subtle red dashed line at $y=1.00$)
- **Responsiveness and Self-Containment:** Portable `.html` files that can be viewed offline without a local server or backend dependencies, supporting both English (`--lang en`, default) and Spanish (`--lang es`).

## 2. Artifact Types and Input Schemas

| Artifact Type | Expected Input JSON Structure | Rendered Components |
| :--- | :--- | :--- |
| `top-ranking` | `{ "top_entities": [ { "rank", "display_name", "total_works", "total_citations", "avg_fwci", "pct_top_10", "institution", "is_mexican_affiliated" } ] }` | Horizontal Plotly bar chart with Viridis scale by FWCI + Comparative table with affiliation badges. |
| `timeseries` | `{ "grouped_by": "publication_year", "results": [ { "dimension", "total_works", "total_citations", "avg_fwci", "total_apc_paid_usd" } ] }` | Dual chart: annual production bars + FWCI line with $1.00$ benchmark + KPI cards. |
| `oa-donut` | `{ "grouped_by": "oa_status", "results": [ { "dimension", "total_works", "total_apc_paid_usd" } ] }` | Interactive donut chart with the 6 Open Access routes + APC expenditure and Diamond volume cards. |
| `dossier-works` | `{ "works": [ { "title", "publication_year", "cited_by_count", "fwci", "oa_status", "authors_disambiguated" } ] }` | Summary cards (Total citations, Mean FWCI, % Top 10) + Filterable table with domestic vs. international breakdown. |
| `network` | `{ "works": [ { "author_names": [...] } ] }` | Interactive PyVis spring-layout graph with nodes weighted by co-authorship. |
